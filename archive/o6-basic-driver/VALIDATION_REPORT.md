# LinkerHand O6 左手 Mac 驱动实测报告

## 硬件与通信

| 项目 | 实测结果 |
|---|---|
| 型号 | LinkerHand O6 左手版 |
| USB-CAN | XCAN-USB，VID:PID `0c72:000c` |
| macOS CAN 后端 | MacCAN PCBUSB 0.13 + python-can 4.6.1 |
| python-can 通道 | `PCAN_USBBUS1` |
| CAN 波特率 | `1,000,000 bit/s` |
| 左手 CAN ID | `0x28` |
| O6 固件版本 | `3.1.1` |

## 六关节顺序

1. `thumb_pitch`：大拇指弯曲
2. `thumb_yaw`：大拇指横摆
3. `index_pitch`：食指弯曲
4. `middle_pitch`：中指弯曲
5. `ring_pitch`：无名指弯曲
6. `little_pitch`：小拇指弯曲

位置、速度和扭矩的协议范围均为 `0..255`。

## 已验证动作数据

| 动作 | 目标位置 | 实际典型位置 |
|---|---|---|
| 张开 | `[250,250,250,250,250,250]` | `[250,249,249,249,250,250]` |
| 握拳 | `[102,18,0,0,0,0]` | `[102,18,0,0,0,0]` |
| 食指弯到 180 | `[250,250,180,250,250,250]` | 可正常到达 |
| 手势一 | `[125,18,255,0,0,0]` | 使用官方 O6 预置 |
| 手势二 | `[92,87,255,255,0,0]` | 使用官方 O6 预置 |
| 手势三 | `[92,87,255,255,255,0]` | 使用官方 O6 预置 |

完整握拳已连续多次验证成功。验证参数为速度 `50`、扭矩限制 `80`；各次最高温度约 `35°C`，六路故障码始终为 `0`。

四指连续波浪动作已在真机验证成功：拇指保持 `[250,250]`，食指至小指采用 `0.12s` 相位差；实测参数为持续 `5s`、频率 `0.8Hz`、幅度 `90`、命令率 `25Hz`、速度 `120`、扭矩限制 `80`。动作结束后位置恢复到约 `[250,249,249,249,250,250]`，最高温度 `40°C`，故障码全部为 `0`。

四指全行程波浪也已真机验证：持续 `10s`、频率 `0.25Hz`、幅度 `250`、相位差 `0.25s`、命令率 `25Hz`、速度 `200`、扭矩限制 `80`。四指实测最小位置为 `[0,0,1,0]`，达到完整握拳行程；结束后恢复张开，最高温度 `36°C`，故障码全部为 `0`。

较低速度 `20–30` 也能闭合，但完整行程需要约 9–13 秒。旧版固定短延时会在手指尚未到位时切换下一姿态，现已改为连续两次进入位置容差后才继续。

## 保护逻辑

- 实际动作必须显式加入 `--execute`。
- 发送动作前读取当前六关节位置。
- 动作过程中检查六路温度和故障码。
- 默认温度上限为 `55°C`。
- 出现非零故障码立即中止。
- 目标位置连续两次进入 ±5 容差才判定到位。
- 循环和 Demo 结束后强制恢复张开。

O6 固件没有回应 `0x36` 电流查询；位置、扭矩、速度、温度和故障查询均正常。这不影响基础驱动。
